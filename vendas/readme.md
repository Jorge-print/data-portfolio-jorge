# Análise de Vendas

Projeto de análise exploratória de dados com foco em desempenho comercial, utilizando Python.

## Objetivo
Identificar padrões de vendas, produtos mais rentáveis e oportunidades de melhoria.

## Tecnologias
- Python (pandas, matplotlib)
- Jupyter Notebook

## Etapas
- Coleta de dados
- Limpeza
- Análise exploratória
- Visualização
- Insights
